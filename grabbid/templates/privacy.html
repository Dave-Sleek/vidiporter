Privacy Policy

Last updated: November 2026

Vidiporter is built for completely anonymous usage. We collect the absolute minimum transient technical data needed to deliver a requested video file and never build user profiles.

1. No Accounts & No Personal Data

You do not need an account, email address, or password to use Vidiporter. We do not use a database to store user records, download histories, or pasted URLs.

2. Ephemeral Video Processing

When you click Download, the selected video is temporarily staged in an isolated temporary directory on the server solely so ffmpeg can merge video and audio streams if needed. Once the file finishes streaming to your browser (or if an error occurs), the temporary directory and all files inside it are immediately deleted.

3. Rate Limiting & Server Logs

To prevent abuse and keep the service responsive, Vidiporter enforces an in-memory rate limit (maximum 10 API requests per minute per IP address). Rate-limit timestamps exist only in short-lived server memory and expire automatically after 60 seconds.

4. Browser Local Storage (No Tracking Cookies)

Vidiporter does not use advertising trackers or third-party analytics cookies. We store only two harmless preferences in your browser's localStorage: your chosen color theme (dark or light mode) and your preferred display language.

5. Third-Party Platforms

Video metadata and media streams are fetched directly from the public URL you supply. Vidiporter is not affiliated with Facebook, Meta, Instagram, X, LinkedIn, TikTok, or Pinterest.
